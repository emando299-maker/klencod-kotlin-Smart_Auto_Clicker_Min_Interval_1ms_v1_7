# Smart Auto Clicker v1.2

## Changes
- Removed the floating launcher/control bubble. Controls are now inside the app.
- Add/remove click points from the main app screen.
- Hide/show all points from the main app screen.
- Double-tap each individual point to start/stop that point independently.
- Updated the main screen to a modern dark card-based layout.
- Kept the interval setting (0 to 86,400,000 ms) and optional text-search feature.

## Setup
1. Install/update the APK built from this project.
2. Enable the app's Accessibility service in Android Settings.
3. Allow display over other apps so click points can be placed on top of the target app.
4. Open Smart Auto Clicker and add points. Drag each point into position; double-tap it to toggle that point.

Note: This ZIP contains the Android project source, not a prebuilt APK.
